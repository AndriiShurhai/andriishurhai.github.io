SYSTEMS / COMBAT SIMULATION2026

Little Delay

A Unity arena-combat prototype built around recording each fighter's input, then replaying both recordings in a battle. My main engineering work was refactoring gameplay simulation away from the presentation and MonoBehaviour lifecycle.

  • Separated the simulation into a dedicated LittleDelay.Simulation assembly; views read state and interpolate between simulation ticks.
  • Built a configurable fixed-step clock (50 Hz by default) and tick-indexed input recording/playback.
  • Centralised projectile movement, swept collision checks, projectile deflection, damage, and round outcomes.
  • Added EditMode tests for replay repeatability, frame alignment, collision edge cases, match flow, and AI information limits.
